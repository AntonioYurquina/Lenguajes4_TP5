# TP1
### Descripción del Trabajo

1) Crear una página HTML que contenga una estructura básica y un botón de
tipo File para subir una imagen. La misma tendrá que ser validada que se
trata de una imagen y mostrar dentro del documento html el contenido
de la misma. Para esta tarea deberá utilizar la API File.
2) Subir el trabajo de la consigna anterior a su cuenta de GitHub y publicarla.
3) Subir la dirección URL del repositorio online y la página publicada (referida
a la consigna anterior) en su cuenta de la plataforma de la universidad.


## Tecnologías utilizadas

- React 19

- Vite 7

- Bootstrap 5

- Git y GitHub Pages para control de versiones y despliegue
